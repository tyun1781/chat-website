# 第四阶段：Ciallo 次元茶话会

## 视觉与交互

按用户指定的 frontend-design 先规划再实现。新方向是“动漫社团茶话会”，替换原来的街角留言窗：浅紫 `#f5f3fb`、深灰紫 `#39384f`、葡萄紫 `#7962aa`、莓粉 `#b75686`、淡天蓝 `#a6cee9`、白色。中文沿用 Noto Sans SC / 微软雅黑，拉丁 Ciallo 使用 Trebuchet MS 斜体；正文安静、左对齐，视觉重点集中在原创矢量耳机少女与 Ciallo 招呼语。

初始页主标语为 Ciallo～，保留点击任意处/Enter 进入、会话内只出现一次、700ms 平滑转场和 reduced-motion。论坛首页为主视觉＋顶部发帖＋帖子流＋社团侧栏。发帖输入提示为“说点什么？”。移动端收起非必要侧栏，帖子、评论与私聊保持可读。页脚有小字 inch.zy 与 GitHub?，链接到 https://github.com/tyun1781/chat-website。

主视觉为本地 Vue/SVG 原创组件，不依赖远端图片。字体加载失败时使用系统字体。没有虚构活跃人数、演示帖子或假成功结果。

## 真实功能

- 保留注册登录、退出、会话恢复、昵称与密码修改。
- 原 messages 作为帖子使用，保留分页、发布、本人删除、幂等与公共 SSE。
- 每帖展开/收起评论；公开倒序分页、登录发布、本人删除；评论事件通过公共 SSE 分发到已展开面板，按 ID 合并、删除墓碑防止复活。
- 悄悄话独立页签：按昵称搜索用户、从帖子/评论作者发起会话、私聊收件箱、历史分页、一对一发送与接收。
- 私聊只使用 `/dm/*` 的独立数据与事件水位，不进入公共流；独立 SSE、断流 HTTP 补拉、失效处理。会话按最近活动展示，后端分页游标原样传递。
- 私聊请求携带 Cookie/CSRF，发送复用失败重试幂等键。用户退出、过期、切换账号或离开私聊时取消请求、关闭连接、清空私聊状态；旧请求使用代际校验，不能回写到新账号。
- 与后端共同确认，对方禁用使用 `RECIPIENT_UNAVAILABLE`，与本人 `ACCOUNT_DISABLED` 分开，避免误清空本人会话。
- 公开帖子和评论草稿在当前页面内保留；切换公开/私聊页签时公开组件保持挂载。未发布内容刷新清空；切换私聊会话或离开私聊清空未发送私信，界面说明此行为。

## 实现文件

`src/App.vue` 管理入场、导航和账号；`components/ForumHome.vue` 为论坛；`components/CommentsPanel.vue` 为评论；`components/InboxPanel.vue` 与 `useInbox.ts` 为独立私聊；`components/ClubIllustration.vue` 为原创插画；`forumTypes.ts` 定义前端新增类型；`forum.css` 为新版视觉层，沿用原基础表单/无障碍样式。
