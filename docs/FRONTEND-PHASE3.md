# 前端第三阶段：核心留言

## 已实现

- 公开真实留言列表，最新在前，每页 20 条，通过不透明游标加载更多。
- 登录后发布 1～500 Unicode 码点留言；成功后清空草稿，失败时保留草稿。
- 每次新提交使用 UUID 幂等键，同一账号同一正文的失败重试复用该键；CSRF 自动重试也保留幂等键。
- 只有本人留言显示删除入口，先展示一次“确认删除”；后端仍负责权限校验。
- 原生 EventSource 接收新增、删除；页面显示连接、实时更新、重连或离线状态。
- 首屏以 `sync.eventCursor` 建流；断流保留现有列表，关闭旧流，经 HTTP 补拉至末页后按已处理游标重连。
- 事件序号按 BigInt 比较，不转 JS Number；按留言 ID 合并，删除墓碑阻止过时数据复活。
- 加载历史分页期间缓存事件，分页合并后排序应用；历史分页返回的快照水位不覆盖实时水位。
- 收到 `sync.reset` / 过期游标时取消旧读取请求、清空旧列表及去重状态，重新首屏同步；代际编号阻止旧请求回写。
- 纯文本显示昵称与正文，正文保留换行；错误信息、加载状态、重复提交阻止、登录失效时草稿保留。

## 设计

继续遵循用户指定的 frontend-design，保留第二阶段“街角留言窗”、雾蓝/钴蓝/黄纸签、中文大标题与平滑入场。新增留言采用安静的单列流与细分隔线，不新增通用卡片阵列；作者头像字签连接原有纸签视觉，删除操作收在本人留言下方。桌面编辑纸签随滚动保持可见，手机保持单列，长昵称及正文可换行。所有状态明确显示真实接口结果，无演示留言或假成功。

## 本地运行

后端运行在 `http://127.0.0.1:3000`；前端目录运行 `npm run dev`，访问 `http://127.0.0.1:5173`。Vite `/api` 代理覆盖 HTTP 和 SSE，保留 Origin。`npm run build` 同时执行 vue-tsc 类型检查及产物构建。

## 必要自检

- 类型检查与生产构建通过。
- 真实页面读取后端公开列表，显示“实时更新中”，表明 SSE 已建立。
- 后端发布“前端本地联通自检”后，已打开页面无需刷新显示这条真实留言；后端随后删除后，页面自动恢复空状态（留言 DOM 数量为 0）。自检留言已清理。
- 390px 手机视口无横向溢出，实时留言截图在 `frontend/artifacts/phase3-live-mobile.png`；浏览器未报告脚本错误。
- 本阶段不组织完整测试，不调用测试 agent；回归、异常组合、并发压力及长期重连验收留给后续专门测试。

## 边界与后续

- 未发布草稿仅保留在当前页面，刷新会清空，界面有明确提示。
- 断线时发布仍可尝试真实请求；失败不会显示成功。服务恢复后自动补拉。
- 管理员界面、邮件验证、密码找回及部署公网仍未包含。
- 没有自动推送 GitHub。
