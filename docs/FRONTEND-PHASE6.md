# 第六阶段前端交付

## 视觉与品牌

- 全站以白色为主、蓝色为强调色、黑灰为正文色，替换原紫粉视觉。
- 导航、入场品牌和页脚统一为 INCH；浏览器标题严格为 `inch-community`。Ciallo 仅作为问候。
- 首页标题使用颜文字 `(｡･ω･｡)ﾉ` 与“喜欢的事，为你分享”。
- 保留现有穹妹横屏、手机与头像素材，以及账号主页、评论、私聊、在线人数和移动布局。

## 真实论坛标签

- 从 `GET /api/tags` 读取日常、动漫、游戏、音乐、分享五个标签，包含加载、失败与重试状态。
- 发帖通过 `POST /api/messages` 提交 `body` 和 `tag`；标签参与客户端待重试请求的幂等匹配。
- 帖子展示可点击标签；桌面侧栏和手机目录均支持“全部”及单标签筛选，替代旧静态话题提示。
- 列表及分页通过 `GET /api/messages?tag=...` 筛选，“全部”不传标签。
- 切换筛选关闭旧实时流、取消旧读取、清理分页和缓冲状态，并以代际保护避免旧响应污染新列表。
- 公共 SSE 仍接收所有标签的事件并推进游标，仅将当前标签的帖子合入显示列表；发布到其他标签时明确提示当前筛选不会显示该帖子。
- 标签为后端固定目录，每帖单标签；本阶段未要求标签管理编辑界面。

## 必要验证

- `npm run build` 通过，包含 Vue/TypeScript 类型检查。
- 真实页面确认标题、白色背景、五个接口标签与旧静态提示移除；检查浏览器无错误输出。
- 查看入场、桌面及手机截图，保留素材正常。390px 与 320px 视口检查无横向溢出。
- 使用本地自检账号实际发布动漫、音乐帖子，验证标签筛选、跨标签发布提示及手机切换；两个自检帖子已通过本人删除操作清理，未修改已有用户帖子。
- 未执行完整回归测试；专项测试 agent 保持暂停。未提交或推送 GitHub。
