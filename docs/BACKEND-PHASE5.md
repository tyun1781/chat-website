## 在线定义

统计本实例仍持有公共 `/api/events` SSE 连接的浏览器，包含匿名访客与登录用户；私聊流不另计。使用服务端随机、签名、HttpOnly 的 presence 会话 cookie 去重，同一浏览器多个标签页只计1人。该cookie不关联用户账号，不持久化，不通过响应正文暴露。

正常关闭连接立即减少引用计数，最后一个标签关闭后删除内存条目。异常网络断开取决于系统何时检测到连接失效，客户端显示另有轮询延迟。不同浏览器、隐私窗口、清除cookie视为不同访客，首次同时打开多个无cookie标签也可能短暂重复，因此显示的是近似在线访客数量。服务重启清空统计与签名密钥，重连会自动建立新标识并重新统计。

## 实现与限制

- `src/presence.ts` 管理活跃浏览器引用计数、签名随机cookie及只读接口。
- 公共列表会预先设置cookie，公共流原生响应也正确携带cookie，兼容 SSE 的 hijack 输出。
- 公共流正常断开、出错、服务关闭和已中止的请求均释放计数；只保留活跃连接条目。
- 公共连接总上限200，每浏览器最多8个，公共建连每IP60次/分钟，人数查询每IP600次/分钟。
- 限流共用既有的最多10000桶、每分钟清理过期桶的机制；活跃访客表最多200项。
- 不更改帖子、评论、私聊的数据库表或持久化事件含义，不需要迁移。
- 单实例实现，后续扩容需共享在线状态。
